# 🧬 Gene Expression Clustering and Pattern Discovery

A bioinformatics and machine learning project for analyzing Alzheimer's disease gene expression data and identifying co-expression patterns.

---

## 📌 Objective

To analyze Alzheimer's disease gene expression data using clustering techniques and identify biologically relevant co-expression patterns.


## 🌐 Live Demo

Access the deployed application here:

https://gene-expression-analyzer.streamlit.app/
---

## ✨ Features

* Data preprocessing
* Data normalization
* Principal Component Analysis (PCA)
* K-Means clustering
* Gene expression heatmap visualization
* Gene correlation heatmap
* Hierarchical clustering dendrogram
* Biological interpretation
* Automatic PDF report generation

---

## 🛠 Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-Learn
* SciPy
* Matplotlib
* Seaborn
* ReportLab

---

## 🚀 Running the Application

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

---

## 📚 Dataset

Gene expression data obtained from the GEO (Gene Expression Omnibus) database.
